# ui-self-healing-ci

This library contains the UI components for the Self-Healing CI landing page.

## Components

- `Hero` - Main hero section with interactive video demo
- `HowItWorks` - Process explanation with step-by-step visualization
- `ValuePropositions` - Three main value propositions with metrics
- `Features` - Technical capabilities showcase
- `Testimonials` - Customer testimonials and success stories
- `CallToAction` - Final call-to-action with trial information

## Usage

```tsx
import {
  Hero,
  HowItWorks,
  ValuePropositions,
  Features,
  Testimonials,
  CallToAction,
} from '@nx/nx-dev/ui-self-healing-ci';
```
